For teachers: how this works

Built for a first-timer working alone

Every step asks for one action, shows where on the grid, and names each part of the grid the first time it appears. New skills get a short demo on the grid first, then the student does the same thing. Mistakes (no = sign, a typed number instead of a formula, a moving reference, dividing by an empty cell) get a plain-language message that points to the exact cell.

Link straight to a lesson

Add the lesson to the page address: excel.html#lesson-3 opens lesson 3. Build it projects: excel.html#build-formulas, excel.html#build-creditcard and excel.html#build-livingwage (add -closer or -deep for the other levels).

Real Excel at the end

Formulas use real Excel syntax, and Download as Excel file saves an .xlsx file with the formulas in it. Lesson 11 walks students through opening it in Excel for the web or the desktop app and turning it in on Canvas. Charts stay on the page: students make them again in Excel with Insert.

Science: analyze your lab data

excel.html#analyze takes students' own lab data (pasted, typed, or sent from a science Raider Labs site with its Analyze in a spreadsheet button) through AVERAGE, STDEV.S, percent error, SLOPE, INTERCEPT, RSQ and a scatter chart, then the .xlsx download. Practice data: #analyze-sample-spring, #analyze-sample-density, #analyze-sample-ramp.

Privacy

Everything runs in the browser. There are no logins. The only things saved are which lessons are done, on this device, and the lab data a student is analyzing, in this browser tab only.
